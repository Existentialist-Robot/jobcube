# working/templates/ — fill-in-the-blank documents

Copy these; don't edit them in place. Each one exists because the format matters downstream — the sweep table feeds the viz, the packet roster feeds the port, the outreach log feeds the follow-up timing.

| Template | Copy to | When |
|---|---|---|
| [`SWEEP_TEMPLATE.md`](SWEEP_TEMPLATE.md) | `working/active/job_sweep_<YYYY-MM-DD>_<slug>.md` | every search sweep |
| [`PACKET_TEMPLATE.md`](PACKET_TEMPLATE.md) | `working/exports/<month>/<app folder>/copy/packet_<slug>_<date>.md` | drafting an application |
| [`OUTREACH_LOG_TEMPLATE.md`](OUTREACH_LOG_TEMPLATE.md) | `working/outreach/<date> - <Org> - <Role>/outreach_log.md` | before submitting, if doing outreach |

Two rules that trip people up:

**Packets are written into their application folder at draft time**, not into `working/active/`. The draft, the reviews, and the final PDFs live together from the first keystroke. `working/active/` holds only the live sweep and the current interview doc.

**Sweep docs are written to disk before anything is reported in chat.** A sweep that only exists in the conversation is gone when the session ends.
